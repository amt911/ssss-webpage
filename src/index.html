Before you trust this with something

Security notes
  • Use it offline. This page never makes a network request, but saving the file and opening it on a machine with networking switched off is stronger still.
  • Keep the shares apart. Shares stored in the same place are not shares, they are a copy of the secret. Different people, different drawers, different buildings.
  • Below the threshold, shares reveal nothing. That is the mathematical guarantee of Shamir's scheme: with fewer than the threshold, an attacker learns nothing about the secret — except its length, which a single share gives away exactly.
  • A checksum is not a signature. Too few shares, a mistyped share or a share from another split are all caught. Deliberate tampering is not: someone who supplies one of the shares can make this page recover a secret of their choosing — without ever learning the real one. Only combine shares you got from people you trust.
  • Nothing is stored. No cookies, no local storage, no history. Reload the page and everything here is gone.
  • Paper works. Shares are plain ASCII and safe to write down, print or stamp into metal.
  • This page cannot protect you from your own machine. Malware, a clipboard manager or somebody reading over your shoulder all sit outside what any web page can defend against. Copying also puts a share on the system clipboard, and on Linux selecting it fills the middle-click selection too.
How it works

The secret is encoded as UTF-8 and prefixed with a version byte and a CRC-32 checksum. That small package is split with shamir-secret-sharing, an audited implementation of Shamir's Secret Sharing over GF(28), which produces one share per byte-wise polynomial. Each share is written out as sss1- followed by standard Base64.

Recovering runs the same path backwards, then checks the version byte and the checksum. The library cannot tell on its own that it was handed too few shares — the threshold is not recorded inside a share — so without that checksum a short set of shares would return convincing nonsense instead of an error.
